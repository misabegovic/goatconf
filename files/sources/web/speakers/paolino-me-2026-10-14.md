## https://paolino.me/about/

I'm Carmine Paolino, a software engineer, founder, and musician in Berlin. I build products, frameworks, and open-source tools across AI, Ruby, and native desktop software. I run Plenty, the company behind this work.
I created RubyLLM, a framework for building AI applications in Ruby, and build Chat with Work, an AI assistant that connects to your work tools. My developer tools include ArchSpec for executable architecture rules, Schematist for JSON Schema, and Kamal Backup for database and file backups.
I also build native desktop apps: Spotifast, a Spotify client, and ZapFast, a WhatsApp client. On Linux, I work on hyprmoncfg and Omarchy plugins. My project directory collects what I build and maintain.
I build the software I need and make it a pleasure to use. I care about speed, beauty, and the details that make a tool feel right, from the interface down to the code.
I help organize Berlin.rb, a monthly meetup for Berlin's Ruby community. I founded Floppy Disco, a Berlin music collective, and make house and disco as Crimson Lake.
I wrote my first scripts at 5 to automate launching my favorite games. I've been hooked ever since.
I got into open source early, running the Italian Gentoo Linux community as a teenager. Studied CS at the University of Bologna, where I published work on large-scale social network analysis with Springer. Then AI at the Free University of Amsterdam, combining deep learning with music. Worked at OLX, Capgemini, and the Alan Turing Institute.
Before Plenty, I co-founded Freshflow: AI that tells supermarkets how much fresh produce to order so less of it ends up in the bin.

## https://rubyllm.com/about/

RubyLLM is an open source Ruby gem that gives developers one consistent framework for building AI applications across OpenAI, Anthropic, Gemini, Vertex AI, Bedrock, Azure AI, Cohere, DeepSeek, Hetzner, Mistral, Ollama, Ollama Cloud, OpenRouter, Perplexity, Deepgram, ElevenLabs, GPUStack, xAI, and OpenAI-compatible providers.
RubyLLM is maintained by Carmine Paolino and developed in the open on GitHub (https://github.com/crmne/ruby_llm). The published gem is available on RubyGems (https://rubygems.org/gems/ruby_llm).
