Asked how "track" was meant in "3-4 talks for each track" (a whole core day, or parallel rooms running at the same time), the organiser wrote, verbatim:

> parallel rooms.

Read as: on each core day the tracks run at the same time in different rooms. Each track has three to four talks of 45 to 60 minutes, with a large break after each talk. This breaks the rules that the core day has one room, one track and no parallel talks (`wiki/org/prds/dates-and-the-core-day.md`, resting on `sources/conversations/2026-10-07--org--freedom-square-and-few-talks.md`). Not yet settled: how many rooms run, and how the keynotes fit.
