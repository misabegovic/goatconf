# User personas

The people GoatConf serves, as roles rather than invented individuals.
Written 2026-10-07 from the operator's vision
(`files/sources/conversations/2026-10-07--org--conference-vision.md`) and first
answers (`files/sources/conversations/2026-10-07--org--first-answers.md`).
Everything not stated there is marked *hypothesis* and should be replaced
with evidence (registration answers, feedback, interviews) as it arrives.

`/rfc`, `/shape` and `/feedback-ingest` read these files. Add a persona
when a group shows up in sources that none of these covers.

| File | Role |
|------|------|
| `attendee.md` | Comes to learn, share and spend time with people. |
| `speaker.md` | Gives a talk or workshop and pays their own way. |
| `extension-host.md` | Adds something to the event: a side event, workshop, booth, activity, venue. |
| `hiring-partner.md` | A company that wants to meet and hire attendees and helps the event in return. |
| `volunteer.md` | Helps run the core on the day. |
