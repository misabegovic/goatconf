title: "Extensions by form or pull request; goatconf will be public"
date: 2026-10-07
kind: conversation
---

Asked how people add their own extension, the organiser picked, by option label: **Form or pull request** ("Hosts who use git open a pull request to a public extensions repository; others use the form").

Asked when a public repository for extensions should be created (goatconf being private at the time), the organiser answered, verbatim:

> goatconf will be public

Read as: the goatconf repository itself is to become public and is where extension pull requests go; no separate extensions repository. Changing the repository's visibility is a public act and the organiser's; as of this note it is still private.

Asked which form collects extension submissions from hosts who do not use git, the organiser picked, by option label: **Same as the CFP (Recommended)** ("One form tool for everything (Tally or Google Forms), so volunteers learn one tool").

Asked who reviews and merges extension pull requests from outside once the repository is public, the organiser picked, by option label: **Agent prepares, you merge** ("An agent checks each extension against the record and charter and comments a summary; you merge").
