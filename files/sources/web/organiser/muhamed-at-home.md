enola
Core contributor
Architectural regression testing for AI-assisted development. I built the constraints program: architectural laws declared over the code graph, checked deterministically in CI, with a Ruby DSL and four gems for Rails teams.
pi-brain
Author and maintainer
An intent store for agentic development on the pi harness: human-gated agent workflows, decision records agents must read before editing, and agent-written knowledge that cannot promote itself. Published on npm, nine tagged releases.
tabula
In private development
Shared memory for teams of agents and people, written in Rust: files and git as the truth, claims as leases so agents never collide, an append-only journal of who did what, and the decisions that belong to people refused by the tool itself.
